ระบบโหลดไม่สำเร็จ
ไฟล์ที่เปิดอยู่อาจเป็นเวอร์ชันเก่าที่ค้างในแคชของเบราว์เซอร์ ลองทำตามนี้:
  1. กด Ctrl+Shift+R (หรือ Cmd+Shift+R) เพื่อโหลดใหม่ข้ามแคช
  2. ถ้ายังไม่หาย กดปุ่มด้านล่างเพื่อล้างแคชของแอป แล้วโหลดใหม่
  3. ตรวจว่าอัปโหลด index.html เวอร์ชันล่าสุดขึ้น GitHub แล้ว
